# Glossary

Brazilian market terms are kept in Portuguese across the repo. Translating them causes more confusion than it saves.

| Term | Meaning |
| --- | --- |
| B3 | Brasil, Bolsa, Balcão: the Brazilian stock exchange |
| Ibovespa | Main B3 stock index; the default benchmark |
| Selic | Brazil's policy interest rate, set by the Copom |
| Copom | Central Bank monetary policy committee |
| CDI | Interbank deposit rate; the reference for "risk-free" returns, tracks the Selic |
| Boletim Focus | Weekly Central Bank survey of market forecasts (inflation, Selic, GDP, FX) |
| IPCA | Official consumer inflation index (IBGE) |
| CVM | Comissão de Valores Mobiliários, the securities regulator |
| Fato relevante | Material fact disclosure a listed company must publish |
| DFP / ITR | Annual / quarterly financial statements filed with the CVM |
| CDA | CVM dataset with fund portfolio holdings (Composição e Diversificação das Aplicações) |
| FIA / FIC FIA | Equity fund / fund that invests in equity fund quotas (feeder) |
| Fundo master | The fund that actually holds the assets, fed by FICs |
| Long biased | Equity fund that can short but stays mostly net long |
| BDR | Brazilian Depositary Receipt: a foreign stock traded on B3 |
| NTN-B | Inflation-linked Treasury bond |
| Tesouro Selic | Treasury bond tracking the Selic; low-risk cash proxy |
| Circuit breaker | B3 trading halt triggered by a large index drop |
| Resolução 4.373 | Rule that lets non-residents invest in Brazilian markets |
| Tickers (MGLU3, ASAI3...) | B3 codes: suffix 3 = common shares, 4 = preferred, 11 = units |
